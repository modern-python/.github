# Support

Where to get help with a `modern-python` project:

- For documentation, start at [modern-python.org](https://modern-python.org) and
  the project's own docs site (linked from each repo).
- For questions and usage help, ask in
  [GitHub Discussions](https://github.com/orgs/modern-python/discussions).
- For bugs and feature requests, open an issue in the relevant repository using the
  provided templates.
- For security issues, see [SECURITY.md](SECURITY.md). Please report them privately,
  not in a public issue.

Please search existing issues and discussions before opening a new one, since your
question may already be answered.
