# GitHub Discussions is the org's only owned channel

GitHub Discussions, org-level at `/orgs/modern-python/discussions` and backed by this repo, is the
only community surface the org runs; `SUPPORT.md` routes every project's users there, and per-repo
tabs stay off except where a repo has traffic to fill one. A Discord server or Telegram group is the
alternative asked for most often, rejected on the empty-room threshold rather than on the durability
of a searchable answer: the scarcest resource is the attention needed to seed a room, and "3
members, last message 2 weeks ago" is a worse signal than a clean Discussions tab. The same
arithmetic rejects enabling Discussions across all 28 repos. The standing principle is to borrow
audiences before building our own, linking back only where the linked page answers the question at
hand, never as a bare repo drop. If rooms ever open they open during launch week, one org-wide room
per platform, never per-repo.
